-- NOME DO PROJETO --

Rota Brasil

-- Descrição e Objetivo --

O Rota Brasil é um guia turístico web desenvolvido para apresentar os principais pontos turísticos de todas as cinco regiões do Brasil (Norte, Nordeste, Centro-Oeste, Sudeste e Sul).

O principal objetivo da plataforma é facilitar a pesquisa de viagens, permitindo que os usuários explorem atrações turísticas famosas, visualizem a localização exata de cada destino integrando com mapas interativos, filtrem atrações por região, busquem por destinos específicos e enviem feedbacks de avaliação do site.
